# KidBank 🏦

A banking simulation app for children aged 9–17. Learn to save, spend smart, and reach your money goals!

## Features

- **Multi-user login** — PIN-protected profiles for up to 3 kids + a parent
- **Two accounts** — Spending (💳) and Savings (🐷) with simulated monthly interest
- **Deposit & Withdraw** — Add or take out money with quick-amount shortcuts
- **Transfer** — Move money between accounts
- **Savings Goals** — Create goals with emoji, track progress, fund from savings
- **Transaction History** — Filterable history with balance summary
- **Money School** — 6 interactive lessons (saving, interest, budgeting, needs vs wants, goals, smart spending) with quizzes
- **Parent Dashboard** — Add kids, give allowance, view all balances and recent activity

## Tech Stack

- React 18 + Vite
- CSS custom properties (no external UI library)
- `localStorage` persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
